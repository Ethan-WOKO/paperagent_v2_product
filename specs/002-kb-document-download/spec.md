# Feature Specification: 知识库原文件下载

**Feature Branch**: `codex/issue-185-react-optimization`
**Created**: 2026-09-14
**Status**: Approved — 用户在完整方案交付后明确回复“批准”
**Issue**: [#221](https://github.com/Ethan-WOKO/paperagent_v2_product/issues/221)
**Input**: 本人可下载私人/公开文档；成员与游客可看到并下载管理员公开文档；他人普通公开资料不新增文件访问；LLM 检索不变。改动最小，使用本地 185 分支，遵循 SDD。

## Clarifications

### Session 2026-09-14

- Q: 是否收紧 LLM 检索？ → A: 用户明确不允许修改，继续本人私有与公开资料检索。
- Q: 本人私人文档是否可下载？ → A: 用户明确要求允许，公开文档同样允许。
- Q: 他人哪些文档新增展示和下载？ → A: 仅管理员公开文档，普通用户公开文档保持现状。
- Q: 工作分支？ → A: 用户明确指定本地 185 分支并要求 SDD。
- Q: 管理员公开资料是否允许其他成员和游客预览？ → A: 用户后续明确要求修改为可预览、可下载；删除仍限本人，LLM 检索不变。预览复用已解析文本，不新增原格式在线查看器。

## User Scenarios & Testing

### User Story 1 - 下载自己的原文件 (Priority: P1)

用户在知识库取回自己上传的私人或公开原文件。

**Why this priority**: 用户明确要求私有文件也能取回。
**Independent Test**: 本人私人与公开文档下载内容分别与上传字节一致。
**Acceptance Scenarios**:

1. **Given** 本人文档有原文件且未删除/归档，**When** 下载，**Then** 获得原始内容和安全可识别文件名，不受公开设置或解析状态影响。
2. **Given** 历史文档无原文件，**When** 查看或尝试下载，**Then** 明确显示不可下载，不用解析文本伪造原文件。

### User Story 2 - 获取管理员公开资料 (Priority: P1)

成员和通过游客体验登录的用户在知识库找到并下载管理员公开资料。

**Why this priority**: 提供平台说明与示例文件的最小共享能力。
**Independent Test**: 成员和游客分别获取同一管理员公开文件，管理员本人列表只有一条记录。
**Acceptance Scenarios**:

1. **Given** 当前有效管理员公开、就绪且当前有效版本的文档，**When** 成员或游客进入知识库，**Then** 在原列表中看到管理员公开标识，可按文件名筛选并下载原文件。
2. **Given** 管理员本人查看，**When** 文档同时属于本人且公开，**Then** 只出现一次。
3. **Given** 他人的管理员公开文档，**When** 查看操作，**Then** 可以预览已解析文本并下载原文件，不增加删除能力；预览不依赖原文件存在。
4. **Given** 公开状态撤销、管理员角色失效、账号删除或文档删除/归档，**When** 从旧页面再次下载，**Then** 拒绝共享访问。

### User Story 3 - 保持原权限与检索 (Priority: P1)

普通用户公开文档的现有搜索用途保持不变，新增文件功能不绕过所有权。

**Why this priority**: 这是用户明确要求的不变边界。
**Independent Test**: A 的普通公开文档仍可由 B 检索到片段，但 B 看不到新增列表条目且无法下载。
**Acceptance Scenarios**:

1. **Given** 他人普通公开文档，**When** 搜索、列文件或下载，**Then** 搜索仍允许，列表和下载不新增访问权。
2. **Given** 他人私人文档，包括管理员私有，**When** 其他身份下载，**Then** 拒绝；管理员身份也不能绕过本人条件。
3. **Given** 未登录访问，**When** 列表或下载，**Then** 要求先通过成员或游客登录。
4. **Given** 本人文档，**When** 上传、预览、删除、检索，**Then** 原行为保持，包括演示种子删除保护。

### Edge Cases

- 原文件缺失提示不可用，存储故障提示重试；无权访问和不存在均不泄露内部位置。
- 中文、空格、路径分隔符或控制字符文件名必须安全处理。
- 下载显示进行状态、抑制同文件重复请求；失败恢复按钮，不把错误响应保存为文件。
- 空列表、文件名筛选无结果、列表失败均有提示。

## Requirements

### Functional Requirements

- **FR-001**: 保留本人文档列表，添加当前有效管理员公开、解析就绪、版本当前有效且未删除的文档；统一按更新时间倒序排列并按文档去重。
- **FR-002**: 本人有原文件且未删除/归档的私人或公开文档可下载，不依赖解析成功。
- **FR-003**: 其他成员与已登录游客可下载符合 FR-001 共享条件的管理员公开原文件。
- **FR-004**: 他人普通公开/私有及管理员私有资料不得通过新增列表或下载访问；每次下载重新判断最新权限。
- **FR-005**: 返回原文件字节和安全文件名；历史无原文件记录明确不可下载，禁止用解析文本代替。
- **FR-006**: 未登录、无权访问、资源缺失、删除/归档、存储故障安全失败，不泄露内部位置。
- **FR-007**: 原列表增加文件名筛选、管理员公开标识和下载操作；支持加载/失败提示、重复请求抑制、不可下载提示；共享行允许解析文本预览但不增加删除权限。
- **FR-008**: 现有上传、本人预览/删除、游客身份、演示种子限制及 LLM/RAG 检索范围保持不变。
- **FR-009**: 复用现有管理员与公开设置，发布者角色失效或账号删除撤销共享；不新增审核、数据迁移或匿名公开存储。

### Key Entities

- **文档**：所有者、公开状态、处理和版本状态、原文件是否保留、文件名。
- **用户**：当前登录访问者和资料发布者，管理员与游客复用既有身份。
- **文件权限**：本人所有权或管理员公开共享条件，与用于回答的检索权限独立。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 所有允许场景原文件字节一致，覆盖中文文件名。
- **SC-002**: 权限矩阵所有拒绝场景均不能取得文件或从新增列表看到受限条目。
- **SC-003**: 成员与游客无需额外授权即可找到、下载可用管理员公开文件；管理员本人零重复条目。
- **SC-004**: 固定场景中普通公开文档跨用户检索仍成功，本人上传/预览/删除保持原行为。

## Assumptions

- 发布沿用管理员上传勾选公开，无审核流程；管理员按访问时有效角色判断。
- 游客为既有体验登录身份，不是匿名访问。
- 共享就绪为 READY、ACTIVE、未删除；本人已删除或 ARCHIVED 不可下载。
- 原列表加标识、文件名筛选和下载，不新增全文搜索或资料中心。
- 当前页面上传已保存原文件，历史无原文件需要重新上传；本次不回填、不扩展上传接口、不增加病毒扫描服务。

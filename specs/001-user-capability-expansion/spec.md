# Feature Specification: 用户能力与后台体验完善

**Feature Branch**: `codex/issue-185-react-optimization`
**Created**: 2026-09-09
**Status**: Accepted for implementation by user
**Input**: 用户授权在当前本地 185 实现四项功能；之后另行开展 Redis 优化。

## User Scenarios & Testing

### US1 - 安装个人 Skill (P1)
用户导入自己的 Skill，查看已安装项，启用、禁用或卸载，并在现有对话中选择使用。
独立验收：A 导入有效 Skill 后刷新仍存在，能够选用；B 看不到且不能使用 A 的 Skill。内置 Skill 继续可用。
无效格式、过大文件、冲突名称必须有明确提示，不得覆盖内置项。

### US2 - 对话发起论文润色 (P1)
用户在工作区或项目页面明确要求润色论文，助手调用现有论文能力，返回可追踪的任务和结果入口。
独立验收：两个页面均可发起、查询进度、查看结果；失败时说明原因，不把排队当作完成。
只能使用本人已有论文材料或经本人项目权限验证的输入。任务重放不得重复创建；已有论文页面流程继续正常。
结果作为论文任务产物交付，不自动覆盖项目源文件。

### US3 - 按需查询本人历史 (P1)
用户提到以前讨论的内容，助手可搜索本人工作区和项目会话，再展开相关历史获取上下文。
独立验收：搜索命中与详情带会话、时间等来源；无结果明确返回空；任意跨用户访问失败。
分页和返回长度有界；历史仅供参考，不作为当前项目文件或执行结果的权威证据。

### US4 - 后台对话区域内部滚动 (P2)
管理员浏览大量游客会话、展开长消息时，对话内容停留在有界区域，邀请码区不会随内容无限下移。
独立验收：大量会话及长消息在桌面和移动宽度下内部滚动；邀请码操作、删除消息和切换用户可用。

### Edge Cases
- Skill 重名、禁用后使用、跨用户卸载、恶意路径或超大内容。
- 论文输入缺失、类型不支持、越权输入、重复启动、模型或任务失败、任务还在运行。
- 历史中无匹配、会话删除、截断分页、其他用户猜测 ID、历史中包含指令。
- 长单词、长消息、多会话及小屏幕布局。

## Requirements

- FR-001: 个人 Skill 必须持久保存、仅本人管理使用，不覆盖内置能力。
- FR-002: 用户可在现有设置与对话入口安装、启停和卸载 Skill；非法输入有可理解提示。
- FR-003: 两个对话页面可发起现有论文润色并查询进度和结果；重复执行同一请求不会重复创建任务。
- FR-004: 论文结果不得冒充已修改项目源文件，异步任务受限查询并可从论文页面继续查看。
- FR-005: 历史检索只读取本人可访问的对话；支持有界搜索、分页与详情展开，覆盖工作区和项目会话。
- FR-006: 历史信息带来源且不能授予权限或替代当前项目证据。
- FR-007: 后台对话区域高度有界、可用鼠标和键盘内部滚动，保留原管理员操作。
- FR-008: 保留现有认证、内置 Skill、论文任务、记忆沉淀、项目验证发布、邀请码功能。

### Key Entities
个人 Skill；用户会话及消息；论文润色任务和结果产物；管理员会话查看区域。

## Success Criteria
- SC-001: 两个用户之间 Skill、论文输入和历史数据越权场景全部拒绝。
- SC-002: 两个对话入口均通过论文发起与进度结果的确定性集成验收。
- SC-003: 本人工作区及项目历史均可命中、展开，分页不会突破返回上限。
- SC-004: 100 个会话及展开长消息不会使邀请码的位置随全部消息长度增长。
- SC-005: 受影响现有功能回归通过；真实模型验收未执行时明确记录，不声称已验证。

## Assumptions
- 首版安装面向声明式 Skill 提示词与允许工具，不在服务器安装执行任意脚本或依赖。
- 复用现有论文格式、任务系统及结果页面；缺少材料时提示用户上传或选择。
- 用户明确授权当前 185 分支直接开发，覆盖默认独立 worktree 要求；按能力分别记录 Issue。
- Redis 性能优化是后续工作，本次只使用项目已有基础设施。

## 目录说明

- `当前有效/`：名称是历史分类，不代表其中内容仍是当前权威；相关结论已由当前 V2 文档承接。
- `历史归档/`：旧实施记录、旧路线和旧评测证据。
- `待实施（建议保留）/`：旧计划中仍有价值的方向索引；已统一提取到当前待办评估文档。
- `待重新评估/`：需要按当前 V2 事实模型重新判断的旧设计。
- `已被替代/`：已经被 V2 合同或产品决定取代的方案。
- `确认废弃/`：明确不再采用的设计选择及原因。

## 使用原则

1. 旧文档中的 `下一步`、`PENDING`、Worker 编号和提交号都是历史状态，不能自动转成当前任务。
2. 历史正文中的旧路径和旧术语用于保留当时证据；若要复用思想，先映射到当前代码、权限模型和持久化合同。
3. 归档不等于删除，也不代表可以按类名批量删除旧代码。

# 研伴新手导览：每个页面是做什么的？

第一次使用，不用先研究所有按钮。先想清楚自己现在要做什么，再打开对应页面就可以。

最常用的三个入口是：**工作区负责提问，知识库负责放资料，项目负责处理一整个文件夹。**

## 先找到你要去的地方

| 你现在想做什么？ | 点哪个页面？ |
| --- | --- |
| 我想问 AI 一个问题 | **工作区** |
| 我想把资料放进去，之后根据资料提问 | **知识库** |
| 我想让 AI 阅读、分析或修改一个文件夹里的内容 | **项目** |
| 我想润色一篇 LaTeX 论文 | **论文** |
| 我想知道 AI 为什么没找到我的资料 | **检索调试** |
| 我想让 AI 记住我的习惯，或纠正它记错的内容 | **长期记忆** |
| 我想选择模型，或处理模型配置问题 | **设置** |

这些入口在左侧导航栏。手机上有些入口会收在“更多”里。界面可以切换中英文，下面会标出几个常见英文按钮。

## 1. 登录与体验：先进入自己的工作空间

**这个页面做什么？**

让你登录账号，继续自己的聊天、资料和项目。还没有账号时，可以进入注册页面；只想先了解软件，可以查看体验入口是否开放。

**页面上看哪里？**

- **用户名和密码**：填写自己的登录信息。
- **登录**：进入软件。
- **注册入口**：按页面要求填写用户名、密码和邀请码。
- **体验入口**：用演示内容了解功能，可能有使用限制。

**第一次怎么开始？**

已有账号，填好信息后点“登录”；没有账号，先向服务方获取注册所需信息。不要把个人敏感资料放进体验账号。

登录后，可以先进入“工作区”试着问一个问题。

## 2. 工作区：和 AI 说你想做什么

**这个页面做什么？**

这是日常聊天的地方。你可以让 AI 解释概念、整理思路、根据资料回答问题，也可以询问研伴的使用方法。

**页面上看哪里？**

- **左侧会话列表**：像聊天记录列表。点击旧会话继续聊，点击“+”开始新话题。
- **中间聊天区域**：显示你的问题和 AI 的回答。
- **下方输入框**：写好问题后点“发送”；附近也有上传附件和选择模型的入口。
- **运行设置**：调整当前聊天的选项。新手暂时不用修改计划模式或选择 Skill。

**第一次怎么开始？**

点“+”新建会话，在下方输入：

> 我正在准备一次课题汇报，请帮我列一个包含研究背景、方法和结果的汇报提纲。

发送后，在中间查看回答。想继续补充要求，就在同一会话接着说。

**如果想根据自己的资料提问：**先到知识库上传资料，再回来告诉 AI 资料的名字。此时不要勾选“禁用知识库”，否则它不能正常使用你需要的知识库检索能力。

### 工作区里的“检索论文”按钮

这不是另一个独立页面。点击“检索论文／Search Papers”，填写研究主题、希望返回的数量和可选的起始年份，再点“开始检索”。结果出现在当前会话的检索区域，可以查看论文信息并打开来源。

例如，主题可以写“图神经网络在交通流预测中的应用”。需要参考文献条目时，勾选“包含 BibTeX”；BibTeX 是 LaTeX 常用的参考文献格式。引用前仍要核对原文。

## 3. 知识库：把以后要用的资料放在这里

**这个页面做什么？**

它相当于资料柜。你可以把论文、笔记、产品说明等放进来，之后让 AI 从相关资料中寻找答案。

这里主要负责**上传和管理资料**。要让 AI 回答问题，上传完成后回到“工作区”。

**页面上看哪里？**

- **上传文档**：选择需要放入知识库的文件。
- **文档列表**：查看自己上传了哪些资料，以及处理到哪一步。
- **状态**：`READY` 表示已经处理好；`PROCESSING` 表示还在处理；`RETRYING` 表示正在重试。
- **Preview／预览**：查看系统实际读出的文字。
- **Public／Private**：分别表示公开和私有。

**第一次怎么开始？**

1. 点“上传文档”，选择一份 PDF、DOCX、TXT 或 MD 文件。
2. 个人资料先不要勾选“将此文档设为公开”。
3. 上传后等待列表显示 `READY`，再点预览看看文字是否正常。
4. 回到“工作区”，输入：

> 请根据知识库中的“课题笔记”，整理三个最重要的结论，并告诉我依据来自哪里。

把“课题笔记”换成你自己的文档名称。上传到 100% 只表示文件传完了，还需要等待后台处理。

**公开之前请想一下：**这份内容是否允许其他用户看到？公开资料可能被其他登录用户通过 AI 检索到，客户资料、密码和未公开研究不要随手勾选公开。

## 4. 项目：让 AI 围绕一组文件开展工作

**这个页面做什么？**

当材料不止一份，或者你需要 AI 分析和修改文件时，使用项目。例如，一个代码工程、一个研究材料文件夹，或一组需要整理的文档。

**页面上看哪里？**

- **左侧“项目”**：选择这次要处理哪个文件夹。
- **左侧“会话”**：查看这个项目里的不同话题。
- **左侧“文件”**：像文件管理器一样查看导入内容，点击文件可以预览。
- **中间任务区域**：显示问题、处理进度、需要你补充的信息和最终回答。
- **下方输入框**：告诉 AI 要做什么。
- **“修改与验证”和“项目版本”**：查看改了什么，下载保存结果，或恢复旧版本。

**第一次怎么开始？**

1. 点“新建项目”，填写名称。
2. 点“Browse／浏览”，选择本地文件夹，再点“Import Project／导入项目”。
3. 查看左侧文件列表，确认需要的文件已经导入。
4. 在项目会话输入：

> 请先介绍这个项目里有哪些主要文件，各自有什么用途。只阅读和解释，不修改任何文件。

第一次先用只读问题熟悉项目。确认理解一致后，再提出修改要求。

**结果在哪里？**

解释性回答在会话里；文件修改要看“修改与验证”和“项目版本”。在目标版本旁点“Export ZIP”可下载项目文件包；需要恢复旧版本时使用“Rollback／回退”。

项目使用的是**导入副本**，不会自动把修改同步回你电脑上的原文件夹。明确要求修改后，符合条件的结果可能自动保存成新版本。如果只想听建议，务必写清“不要修改文件”。

## 5. 论文：按步骤检查和润色 LaTeX 论文

**这个页面做什么？**

它是专门的论文润色工作台，会围绕论文结构、章节表达和相关文献开展处理，并让你查看建议和结果。

这个页面接收的是 **`.tex` 论文文件**，可附加 **`.bib` 参考文献文件**。如果你现在只有 Word 或 PDF，先用项目或知识库阅读资料，不要把它们当成这里的同一种输入。

**页面上看哪里？**

- **稿件上传区**：选择要处理的论文和参考文献文件。
- **润色参数**：设置目标语言等要求。第一次可以先检查默认值是否合适。
- **任务状态和阶段**：查看处理进展，或是否在等待你的确认。
- **修改建议和审阅区域**：查看章节变化、支撑文献，并作出采纳或拒绝的选择。
- **“产物”和历史任务**：下载结果，或重新打开以前的润色记录。

**第一次怎么开始？**

上传 TEX → 检查目标语言 → 点“运行工作流” → 按提示确认结构 → 查看建议 → 下载结果。

还没有合适的文件，可以先使用页面提供的示例，熟悉整个流程。

**最容易误会的地方：**“结构确认待处理”不是程序卡住了，而是需要你回答。点“去确认”，选择符合论文实际情况的选项并提交。下载后也要核对内容，不要把润色完成理解为学术结论已经被证明。

## 6. 检索调试：看看系统到底找到了哪段资料

**这个页面做什么？**

当你已经上传资料，AI 却回答“没找到”时，可以来这里检查。平时正常问答不需要经常打开这一页。

它显示的是**找到的原文片段**，不会像聊天页那样替你组织一段完整回答。

**页面上看哪里？**

- **Query**：输入要查的问题或关键词。
- **Top K**：希望查看多少个结果，可以先保持默认。
- **Search／搜索**：开始查找。
- **结果列表**：看文件名和正文片段是否与你的问题有关。
- **诊断区域**：提供进一步的检索信息，新手可以先不看。

**第一次怎么开始？**

在 Query 输入“课题笔记 实验步骤”，点击搜索。找到对应文档并看到正确片段，说明这次检索找到了相关内容；然后回到工作区提出完整问题。

找不到时，先检查知识库里的文档是否已经 `READY`，再尝试用更短、更具体的关键词。不要把结果得分当作答案正确率。

## 7. 长期记忆：查看 AI 记住了哪些习惯

**这个页面做什么？**

它用于管理适合长期保留的信息，例如你偏好的回答语言、研究方向，或某个项目已经确定的要求。

整篇论文放知识库；“解释时请先给结论，再举例”这样的习惯更适合放长期记忆。

**页面上看哪里？**

- **新增记忆**：自己写下希望长期保留的信息。
- **记忆列表**：查看具体内容、适用范围和确认状态。
- **确认、更正、拒绝、删除**：决定哪些内容准确、哪些不应继续使用。
- **立即沉淀**：请 AI 从尚未处理的对话中整理可能值得记住的信息。
- **自动定期沉淀**：按页面显示的周期检查新对话，默认关闭。

**第一次怎么开始？**

新增一条用户范围的记忆，例如：

> 我希望默认使用中文解释，第一次出现专业缩写时说明它的含义。

也可以先点“立即沉淀”，再逐条检查提取结果。自动提取的内容处于“待确认”时，还不会用于后续回答；正确的确认，错误的更正或拒绝。

重要要求最好在本次任务里再写一次，不要假定 AI 每次都会用到所有记忆。

## 8. 设置：选择回答问题的模型

**这个页面做什么？**

它决定使用哪个模型、哪些技能可用，以及新会话是否默认可以查知识库。如果服务方已经配置好，第一次使用通常不用改。

**页面上看哪里？**

- **默认提供商和默认模型**：选择用于处理请求的模型。
- **知识库 RAG**：可以理解为“允许新会话默认查资料”。
- **技能／Skills**：查看和启用可用的任务指导，新手可以先保持原设置。
- **自定义模型**：供有模型服务信息的用户添加配置。
- **保存设置**：修改后点击这里保存。

**第一次怎么开始？**

先确认有可用模型。能正常聊天就先使用；出现“模型不可用”“缺少密钥”等提示时，再查看设置或联系服务方。不知道 API 地址或密钥该填什么时，不要猜填。

API Key 可以理解为调用模型服务的密钥，不是你的研伴登录密码。不要把它放进普通聊天或公开文档。已有密钥的输入框留空表示保留原值，不是删除。

## 用一个小任务，把页面连起来

假设你要根据一份“课题笔记”准备组会汇报：

1. **去知识库放资料。** 上传笔记，等待 `READY`，预览确认文字正常。
2. **去工作区提要求。** “请根据课题笔记，整理一个五分钟的汇报提纲。”
3. **继续在工作区调整。** “把方法部分讲得更通俗，保留实验数据。”
4. **只有没找到资料时，才去检索调试检查。** 不需要每次提问都做这一步。
5. **如果以后都想采用这种表达方式，去长期记忆记录偏好。**

如果你的目标变成了“整理整个研究文件夹，并生成一个新的 Word 文档”，就改用**项目**：导入文件夹 → 说明整理要求和新文件名 → 查看结果 → 从项目版本导出文件包。不要把“聊天里给出了提纲”误认为已经保存了 Word 文件。

## 先记住这几个词就够了

| 页面里的词 | 可以怎样理解？ |
| --- | --- |
| 会话 | 围绕一个话题的聊天记录 |
| 知识库 | 供 AI 查找内容的资料柜 |
| 项目 | 一组需要一起阅读或处理的文件 |
| 产物 | 系统实际生成、供你查看或下载的结果文件 |
| 项目版本 | 某一次保存下来的项目文件状态 |
| 公开 | 其他登录用户可能通过检索使用其中的内容 |
| 待确认 | 需要你检查或回答之后才能继续相应操作 |

如果看到“管理后台”，那是管理员账号的专用入口。普通客户不需要它，也不用为了使用上述页面申请管理员权限。

遇到不会用的按钮，向 AI 或服务方说清楚：**“我在什么页面，点了什么，现在显示什么，我希望完成什么。”** 这比只说“不能用”更容易定位问题。发送截图前记得遮盖敏感资料。
